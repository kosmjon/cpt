# CPT 8000 Special Keys
There are 5 columns of 5 keys each.
Keys are square with a realistic 3D appearance and a slight click and visual indication when pressed.  Some keys are lock/unlock. There is likely a screen indication when a locked key is locked on. Text on keycaps is all caps.

## Column 1
Code
Clear Tab Set (3 lines of text on keycap; locking)
Hold
Mar Set (two lines of text on keycap)
Mat Rel (two lines of text )
