# MOL80 Assembler — Implementation Plan

- [x] 1. Scaffold the Rust crate and CLI skeleton
  - Created `mol80asm` cargo binary+library crate with the module layout from the design.
  - CLI accepts an input file with `--tokens`/AST modes and returns proper exit codes (non-zero on error).
  - Front-end pipeline (lex → parse → AST) runs end to end; binary/listing/transpile emitters are future work.
  - _Requirements: 6.4, 7.1_

- [x] 2. Implement the column-aware lexer and token types
  - [x] 2.1 Defined `Token`, `TokenKind`, and `Span` with line/column tracking.
    - _Requirements: 7.1_
  - [x] 2.2 Tokenize labels from columns 1–10 (no trailing colon) vs. instruction field.
    - _Requirements: 1.1, 1.2, 1.3_
  - [x] 2.3 Tokenize registers, `(HL)`, `(STK)`, and operators with longest-match (`+*`,`-*`,`**` before `+`,`-`,`*`).
    - _Requirements: 2.4, 2.5_
  - [x] 2.4 Implemented `parse_number` for binary/hex/decimal behind one function (placeholder radix markers, [VERIFY]).
    - _Requirements: 5.5_
  - [x] 2.5 Slice each line into label / instruction / comment zones by column; discard the inline comment field (column-based, no delimiter). Comment column is a single named constant `COMMENT_COL` ([VERIFY]). (Block comments: pending confirmation of form.)
    - _Requirements: 1.5, 1.6_
  - [x] 2.6 Unit tests for each token category (in `tests/frontend.rs`).
    - _Requirements: 1.1, 2.4, 5.5_

- [x] 3. Define the AST
  - Implemented `Program`, `Line`, `Item` (Move/AluOp/Jump/CondJump/CondBlock/Empty), `Operand`, `Condition`, `AluOp`, `JumpTarget`, reusing `FlagKind`/`Reg`. `DataDef`/`Directive` pending [VERIFY] syntax.
  - _Requirements: 2.*, 4.*_

- [x] 4. Build the authoritative ISA table (data-driven)
  - [x] 4.1 `IsaEntry { opcode, pattern, i8080, len, verified }` seeded from the scan. Regular families (MOV, MVI, INR, DCR, ALU, LXI) generated by 8080 encoding rules; opcodes cross-checked against the scan's decimal values.
    - _Requirements: 8.1_
  - [x] 4.2 Tentative logical ALU rows (ANA/ORA/XRA) and BC/DE/SP LXI marked `verified: false`; queryable via the `verified` flag.
    - _Requirements: 8.3_
  - [x] 4.3 Tests: opcode uniqueness, 1–3 length range, verified-flag inventory (in `tests/isa.rs`).
    - _Requirements: 8.2, 8.3_
  - [x] 4.4 Encoder (`isa/encode.rs`): AST Move/AluOp → bytes, with encoding snapshots verified against the scan (`C:(HL)`→0x71, `5:A`→0x3E 05, `A+B:A`→0x80, `C+1:C`→0x0C, LXI little-endian, etc.).
    - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5_

- [x] 5. Implement the recursive-descent parser
  - [x] 5.1 Parse optional leading label + one `Item` per line.
    - _Requirements: 1.1, 1.3_
  - [x] 5.2 Parse simple instructions (`src:dst`, `n:A`, `nn:HL`) into AST operands.
    - _Requirements: 2.2, 2.3, 2.4_
  - [x] 5.3 Parse arithmetic/logical forms targeting A (`A+B:A`, `A+*C:A`, etc.).
    - _Requirements: 2.5_
  - [x] 5.4 Parse `Fx=0?/Fx=1? /s` conditional jumps.
    - _Requirements: 4.1_
  - [x] 5.5 Parse `cond ? ( body )` conditional blocks (multi-line body as a line sequence; flag and compare conditions).
    - _Requirements: 4.2, 4.4_
  - [x] 5.6 Error recovery to next line so multiple errors report in one run.
    - _Requirements: 6.6, 7.2_

- [x] 6. Implement the diagnostics subsystem
  - Collectible `Diagnostics` with file/line/column, severity, message, optional snippet; `render()` formatter. Verified reporting multiple errors in one run with recovery.
  - _Requirements: 7.1, 7.2, 7.3_

- [x] 7. Pass 1 — layout and symbol table
  - [x] 7.1 Lowering to a flat `Emit` list with known sizes; location counter assigns addresses.
    - _Requirements: 3.1, 3.4_
  - [x] 7.2 `SymbolTable` records labels; duplicate-label errors with both locations.
    - _Requirements: 1.4_
  - [x] 7.3 Collision-free internal labels (`@Lnnnn` prefix the lexer can't produce) for cond blocks.
    - _Requirements: 4.4, 4.5_

- [x] 8. Pass 2 — code generation
  - [x] 8.1 Encode instructions via the ISA table; 8-bit/16-bit immediates little-endian.
    - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5_
  - [x] 8.2 Resolve label references; undefined-label errors; forward refs via two passes (verified).
    - _Requirements: 3.1, 3.2, 3.3_
  - [x] 8.3 Lower `Fx=v? /s` to the correct conditional JMP (all 8 flag/value combos tested).
    - _Requirements: 4.1_
  - [x] 8.4 Lower `cond ? ( body )`: CMP + inverted branch to internal label + body (flag and A=reg forms).
    - _Requirements: 4.2, 4.3_
  - [x] 8.5 Report unrecognized instructions/operands with span; emit no bytes for them.
    - _Requirements: 2.6_

- [ ] 9. Data and directive support ([VERIFY] syntax; isolate so changes are local)
  - [ ] 9.1 Byte/word/string/reserve data definitions (word little-endian).
    - _Requirements: 5.1, 5.2, 5.3, 5.4_
  - [ ] 9.2 ORG / EQU directives feeding the location counter and symbol table.
    - _Requirements: 3.4_

- [x] 10. Output emitters
  - [x] 10.1 Binary image written only on clean success; nothing written on failure (verified).
    - _Requirements: 6.1, 6.4_
  - [x] 10.2 Hex listing (`ADDR: BYTES`) via the CLI default mode. (Source-paired listing is a future refinement.)
    - _Requirements: 6.2_
  - [x] 10.3 Transpile emitter (`src/emit/transpile.rs`) to standard Intel 8080 mnemonics, reusing ISA `i8080`; mirrors codegen lowering so output is byte-equivalent. CLI `--asm` mode. Covers MOV/MVI/LXI/ALU/INR/DCR/jumps/cond-blocks/CALL/RET/PUSH/POP.
    - _Requirements: 6.3_

- [ ] 11. End-to-end tests and fixtures
  - [ ] 11.1 Encoding snapshots from the scan (`C:(HL)`→0x71, `n:A`, `nn:HL`, `/s`).
    - _Requirements: 2.1, 2.2, 2.3, 2.4_
  - [ ] 11.2 Control-block lowering byte-sequence tests.
    - _Requirements: 4.1, 4.2, 4.3_
  - [ ] 11.3 Error-path tests (duplicate/undefined labels, unknown instruction, multi-error run).
    - _Requirements: 1.4, 2.6, 3.2, 7.2_

- [ ] 12. Validation harness (activate once real MOL80 source is available)
  - Round-trip: MOL80 → transpiled 8080 → third-party assembler → diff bytes vs. `mol80asm` binary.
  - _Requirements: 6.3_

- [ ] 13. Resolve [VERIFY] items against the official MOL80 manual
  - Update ISA table (logicals, rotates, full 256 entries), radix markers, data/directive/comment syntax, conditional nesting/else; flip `verified` flags; extend tests.
